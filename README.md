# Codebase Technical Assessment: Guidebook & Rubric

A practical framework for measuring and managing technical debt in software projects. Developed for use in [Open Source with SLU](https://oss-slu.github.io) experiential learning programs, but applicable to any team that wants to understand and improve code quality systematically.

## Contents

- **[Guidebook](Codebase%20Technical%20Assessment_%20Guidebook.md)** — How to prepare for and conduct technical debt assessments, identify debt, prioritize findings, communicate results, and plan remediation
- **[Rubric](Codebase%20Technical%20Assessment_%20Rubric.md)** — Structured scoring framework across code quality dimensions

## Companion Guidebook

- **[Code Futures: Reading Automated Analysis of Your Codebase](https://github.com/oss-slu/guidebook_code_futures)** — The automated counterpart to these documents. Where this guidebook is a person reading a codebase and exercising judgement, Code Futures is about what a tool can establish on its own, what it cannot see, and how much to believe its output.

The two cover each other's blind spots. Automation finds every repository without branch protection in under a minute and will never tell you the domain model is wrong. These documents remain the assessment instrument; an automated report produces evidence to bring to an assessment.

## Who This Is For

- Tech Leads conducting self-assessments
- Mentors and advisors evaluating projects
- New maintainers getting oriented to a codebase
- Teams preparing for handoffs
- Anyone wanting to understand technical debt systematically

## Usage

These documents are designed to be used together. Start with the Guidebook to understand the assessment process, then apply the Rubric to score specific dimensions of your codebase.
